# 🚀 Customer Sentiment Analysis Dashboard 📊

![Demo of Customer Sentiment Analysis](./assets/demo.png)

## Summary

This prompt analyzes customer feedback from multiple sources (reviews, support tickets, social media, surveys) to identify sentiment trends, common pain points, and actionable insights for improving customer experience.

## Prompt 💡

Analyze the following customer feedback data and provide a comprehensive sentiment analysis report including:
- Overall sentiment score (Positive/Neutral/Negative percentage breakdown)
- Top 5 recurring themes or topics
- Most mentioned pain points with frequency count
- Positive highlights and what customers love
- Sentiment trend over time (if timestamps provided)
- Actionable recommendations to improve customer satisfaction
- Priority areas requiring immediate attention

Format the output with visualizable tables, charts description, and executive summary.

Customer feedback data:
{Paste_Customer_Feedback_Data_Here}

Time period: {Specify_Date_Range}

## Description ℹ️

This prompt processes customer feedback from various sources and generates a comprehensive sentiment analysis report. It helps businesses understand customer emotions, identify improvement areas, and make data-driven decisions to enhance customer experience.

## Instructions 📝

1. Make sure you have Copilot for Microsoft 365 in your tenant
2. Open the Microsoft Teams app or Copilot in your browser
3. Open the Copilot app within Teams
4. Paste the prompt in the Copilot app
5. Replace {Paste_Customer_Feedback_Data_Here} with your feedback data
6. Specify the time period for analysis

### Improvise Usage 🚀

1. Compare sentiment across different customer segments
2. Analyze sentiment by product or service line
3. Track sentiment changes after implementing improvements
4. Include competitor sentiment comparison
5. Request correlation with business metrics (revenue, churn rate)
